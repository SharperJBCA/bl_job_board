# bl_job_board

Static Jekyll job board for Prospero Station.

## Supabase-powered scheduling

This repo now includes an optional Supabase integration for:
- player self-registration (account + profile display name)
- GM session posts
- player session signups

See [SUPABASE_SETUP.md](SUPABASE_SETUP.md) and run [`supabase_schema.sql`](supabase_schema.sql) in your Supabase project.
